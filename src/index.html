Timevault

Powered by drand and tlock-js

ソースコードは Github で確認できます。

Timevault は、指定した時刻になるまで解読できない「タイムロック暗号」を作成・復元するツールです。
暗号化も復元もすべてお使いのブラウザ内で完結し、サーバーに秘密データが送信されることはありません。

使い方:

  • 作成 (Encrypt): 暗号化したいテキストを入力（またはファイル読み込み）し、解除したい日時を指定して「暗号化」されたテキストを生成します。
  • 復元 (Decrypt): 暗号化されたテキストを貼り付けると、指定日時を過ぎていれば内容が表示されます。

※本サイトは drand Mainnet (quicknet) を使用しています。
※復元にはインターネット接続が必要です（時刻認証のため）。
